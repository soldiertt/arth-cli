# Angular 14 → 22 Upgrade Plan (arth-cli)

## Objective

Upgrade `arth-cli` from **Angular 14.0.6 → Angular 22**, one major at a time via `ng update`
(Angular Update Guide), and modernize to: **built-in control flow**, **standalone components**,
**signal inputs/outputs/queries**, **`inject()`**, **functional guards/interceptor**, and **OnPush**
change detection while keeping Zone.js.

## Locked decisions

- **Libraries:** replace unmaintained ones with maintained equivalents; drop `luxon-angular` and
  `core-js`; keep `luxon` and `@ngrx/entity`.
- **Change detection:** keep **Zone.js** (ensure `provideZoneChangeDetection()` survives v21);
  adopt **OnPush** deliberately.
- **Verification:** `ng build` (dev + prod) + manual smoke after every hop, one commit per hop.
- **Lightbox replacement:** `@pierresh/ngx-lightbox` (keeps the original `LightboxModule` /
  `Lightbox` / `LightboxConfig` / `IAlbum` API → near drop-in).

## Baseline facts (verified)

- Angular 14.0.6 / TS 4.7.2 / RxJS 7.5 / zone.js 0.11.6; NgRx 14 `store`/`effects`/`entity`
  (`entity` used by ~15 reducers).
- 6 NgModules: `AppModule`, `WebsiteModule`, `AdminModule`, `SharedModule`, `SharedServicesModule`,
  `RestModule`; ~53 components; class-based `AuthGuard`/`AdminGuard`; class-based `RequestInterceptor`.
- NgRx state: root `{ profile }` + two feature states `'site'` (`SiteState`) and `'admin'` (`AdminState`).
- Routes are defined via `RouterModule.forChild` in each feature module (`website.routes.ts`,
  `admin.routes.ts`); `forRoot([])` has no routes.
- Templates use `*ngIf`/`*ngFor`/`ng-template`/`ng-container`/`async as x` extensively; no `@if`/`@for` yet.
- No `changeDetection` set anywhere (→ will default to OnPush at v22); only `home-news` sets OnPush.
- `ngx-lightbox` 2.6.1 (detail, advanced-article-box, custom-knife), `ngx-toastr` 15 (2 admin
  components), `luxon-angular` 5 (only `LuxonModule` in `SharedModule`; **pipes unused**), `luxon` 2
  (`DateTime` in one effect), `jquery` 3.6 + `@types/jquery` 2.0.48 (mismatch), `bootstrap` 5.1.3,
  `@fancyapps/fancybox` 3, `auth0-js` 9, `file-saver` 2, `core-js` 2.5.1 (unused).
- No tests, no Karma config, no `test` builder → `ng test` already broken.
- `angular.json` uses webpack `@angular-devkit/build-angular:browser` + `polyfills.ts` +
  `fileReplacements` for `production`/`test`.
- Deploy: `npm run build-prod` → upload `dist` to `/www` (README).
- Stale unused `src/tsconfig.app.json` exists.

## Version matrix (per-hop minimums)

| Hop | Angular | Node.js | TypeScript | Key breakages |
|-----|---------|---------|------------|---------------|
| 0 | 14.0 | 18.20.x | 4.7 | baseline |
| 1 | 15 | 18.20.x | ~4.8.4 | TSLint removed |
| 2 | 16 | 18.20.x | ~4.9.5 | `takeUntilDestroyed` |
| 3 | 17 | 20.9+ | ~5.2.x | control-flow syntax; `browserTarget`→`buildTarget` |
| 4 | 18 | 20.9+ | ~5.4.x | `relativeLinkResolution` removed |
| 5 | 19 | 20.11.1+ | ~5.5–5.8 | **standalone default** |
| 6 | 20 | 20.19+/22.12 | ~5.8 | `DOCUMENT`→core; `afterRender`→`afterEveryRender` |
| 7 | 21 | 20.19+/22.12 | ~5.9 | **zoneless default**; host bindings type-checked |
| 8 | 22 | 22.22.3+/24.15+/26 | ~6.0 | **OnPush default**; `platform-browser-dynamic`; webpack builders deprecated |

NgRx moves in lockstep (`@ngrx/store|effects|entity` @ N for Angular N; NgRx 22 needs Angular `^22`).
RxJS to `7.8.x` by v22.

## Ordered task list

### Task 0 — Baseline & tooling
1. `git checkout -b upgrade/angular-22`; save the current `dist` as a rollback artifact.
2. Add `.nvmrc`; document the Node-per-hop requirement.
3. `npm ci`; `npm run build-prod`; run the smoke checklist (below) to record the baseline.
4. Commit "chore: baseline before Angular 22 upgrade".

### Task 1 — Hop to Angular 15
1. Node 18.20.x; `ng update @angular/cli@15 @angular/core@15`.
2. `ng update @ngrx/store@15 @ngrx/effects@15 @ngrx/entity@15`.
3. Remove `luxon-angular` (`LuxonModule` import/export in `shared.module.ts`; its pipes are unused),
   `core-js`, `tslint.json`, and stale `src/tsconfig.app.json`. Bump `luxon` to `^3`.
4. Bump `ngx-toastr` to `16`. `npm install`; build; smoke; commit.

### Task 2 — Hop to Angular 16
1. Node 18.20.x; `ng update @angular/cli@16 @angular/core@16`; NgRx `@16`.
2. Bump `ngx-toastr` to `17`. Build; smoke; commit.

### Task 3 — Hop to Angular 17
1. Node 20.9+; `ng update @angular/cli@17 @angular/core@17`; NgRx `@17`.
2. Bump `@types/jquery` to `^3.5` (match `jquery` 3.6). Bump `ngx-toastr` to `19.x`.
3. Accept the `browserTarget`→`buildTarget` dev-server migration. Build; smoke; commit.

### Task 4 — Hop to Angular 18
1. Node 20.9+; `ng update @angular/cli@18 @angular/core@18`; NgRx `@18`.
2. Fix the removed `relativeLinkResolution: 'legacy'` (accept migration) and re-verify relative
   `routerLink`s in website + admin trees. Bump `bootstrap` to latest 5.x (optional).
3. Build; smoke; commit.

### Task 5 — Hop to Angular 19 (standalone migration)
1. Node 20.11.1+; `ng update @angular/cli@19 @angular/core@19`; NgRx `@19`.
2. Swap `ngx-lightbox@2.6.1` → `@pierresh/ngx-lightbox@19` and update the `angular.json` lightbox
   CSS path to `node_modules/@pierresh/ngx-lightbox/lightbox.css`. No component code changes
   (`Lightbox`/`LightboxConfig`/`IAlbum` are the same). `npm install`; build; smoke.
3. Run the standalone migration in **three sequential passes**, building + smoking between each:
   - `ng generate @angular/core:standalone` → "Convert all components, directives and pipes to standalone"
   - `ng generate @angular/core:standalone` → "Remove unnecessary NgModule classes"
   - `ng generate @angular/core:standalone` → "Bootstrap the application using standalone APIs"
4. **Relocate feature-module providers** into the bootstrap providers (the schematic does NOT do
   this). Merge these into `bootstrapApplication`'s `providers`:
   - `SharedServicesModule`: `ArthuriusEventsService`, `Auth0Service`, `I18nService`, `PictureService`, `SessionService`, `UploadService` (and standalone `I18nPipe`).
   - `RestModule`: every `*RestService`, `{ provide: 'REST_ENDPOINT', useValue: environment.restEndpoint }`.
   - `WebsiteModule.providers`: `JQueryService`, `MailService` (guards handled in Task 8).
   - Replace `HTTP_INTERCEPTORS` with `provideHttpClient(withInterceptors([requestInterceptor]))`.
5. Apply the module→standalone provider mapping (table below). Merge `websiteRouterConfig` +
   `adminRouterConfig` into one `app.routes.ts` and register with `provideRouter(routes)`.
6. Delete now-empty NgModule files; `AppComponent` becomes the standalone root; remove
   `@angular/platform-browser-dynamic` from deps.
7. Build; full smoke; commit.

### Task 6 — Hop to Angular 20
1. Node 20.19+/22.12; `ng update @angular/cli@20 @angular/core@20`; NgRx `@20`.
2. Bump `ngx-toastr` to `20`.
3. Migrate to the **application builder** (`@angular-devkit/build-angular:application`): move
   `main`/`browser`/`polyfills`; set `polyfills: ["zone.js"]`; delete `src/polyfills.ts`; keep
   `styles`/`scripts`. Set `outputPath` to the deploy layout.
4. `ng generate @angular/core:control-flow` (all `*ngIf`/`*ngFor`/`ngSwitch`/`ng-template` →
   `@if`/`@for`/`@empty`/`@switch`/`@let`; verify `async as x` patterns).
5. `ng generate @angular/core:inject` (constructor DI → `inject()`).
6. Remove now-unneeded `CommonModule`/`BrowserModule` imports. Build; smoke; commit.

### Task 7 — Hop to Angular 21
1. Node 20.19+/22.12; `ng update @angular/cli@21 @angular/core@21`; NgRx `@21`.
2. Confirm the zoneless migration added `provideZoneChangeDetection()` and that jQuery/Fancybox/
   Bootstrap/auth0 callbacks still trigger change detection. **Do not remove Zone.js.**
3. Fix host-binding type errors surfaced by default type-checking.
4. `ng generate @angular/core:signal-input-migration`,
   `ng generate @angular/core:output-migration`,
   `ng generate @angular/core:signal-queries-migration`.
5. Manual fixes the schematics skip:
   - `website/components/form.component.ts`: abstract `@Directive()` base with two `@Output()`s →
     `output()`.
   - `shared/service/arthurius-events.service.ts`: `@Output()` in a service is invalid → replace with
     a `Subject`/signal consumed by subscribers.
6. Build; smoke; commit.

### Task 8 — Hop to Angular 22 (finalization)
1. Node 22.22.3+/24.15+/26; `ng update @angular/cli@22 @angular/core@22`; NgRx `@22`.
2. Switch builder package to `@angular/build:application` + `@angular/build:dev-server`
   (webpack builders deprecated in v22). Verify `styles`/`scripts`/`assets` still resolve.
3. Replace `ngx-toastr` with `ngx-mat-toast@^22` (+ `@angular/material`/`@angular/cdk`), using its
   `ToastrService` adapter first; update the 2 admin call sites. Swap `@pierresh/ngx-lightbox` to `22`.
4. Convert guards/interceptor to functions: `authGuard: CanActivateFn`, `adminGuard: CanActivateFn`
   (returns `Observable<boolean>`), `requestInterceptor: HttpInterceptorFn`; reference them directly in
   route `canActivate` arrays. Remove class versions.
5. **OnPush audit** (components with undefined `changeDetection` become OnPush): fix imperative
   field mutation in `subscribe(...)`, jQuery/Fancybox callbacks, `setTimeout`, and PayPal callbacks.
   Known candidates: `detail`, `custom-knife`, `advanced-article-box`, `home`, `cart-wizard`,
   `cart-navigation`, admin list/edit components (toastr), `profile*`, `header`. Prefer signals /
   `computed` / `toSignal(store.select(...))`; fall back to `ChangeDetectionStrategy.Eager` with a
   TODO where conversion is risky.
6. Bump `zone.js` to latest `0.15.x`; TS is now 6.0 (resolve tsconfig deprecations from the
   migration: `moduleResolution` → `bundler`, target/lib → `es2022+`, module → `es2022`; add
   `skipLibCheck: true` if old `@types`/`auth0-js` break).
7. Remove `@angular/platform-browser-dynamic`. Build prod; full smoke; update README/deploy path for
   the new `dist/arth-cli/browser` layout; commit and tag.

## Module → standalone provider mapping (Task 5)

| Removed usage | Replacement |
|---------------|-------------|
| `platformBrowserDynamic().bootstrapModule` | `bootstrapApplication(AppComponent, { providers: [...] })` from `@angular/platform-browser` |
| `BrowserModule` / `BrowserAnimationsModule` | `provideAnimations()` (drop `BrowserModule` for standalone) |
| `HttpClientModule` | `provideHttpClient(withInterceptors([requestInterceptor]))` |
| `RouterModule.forRoot/forChild` | `provideRouter([...websiteRouterConfig, ...adminRouterConfig])` |
| `StoreModule.forRoot(rootReducers)` | `provideStore(rootReducers)` |
| `StoreModule.forFeature('site', reducers)` | `provideState('site', reducers)` |
| `StoreModule.forFeature('admin', reducers)` | `provideState('admin', reducers)` |
| `EffectsModule.forRoot([...])` / `forFeature([...])` | `provideEffects([...])` (all effects in one call) |
| `ToastrModule.forRoot()` | `provideToastr()` (≤21) / `provideNgxMatToast()` (v22) |
| `LightboxModule` | `importProvidersFrom(LightboxModule)` from `@pierresh/ngx-lightbox` |
| `FormsModule` / `ReactiveFormsModule` (via `SharedModule`) | import directly in each standalone component that uses them |
| `LOCALE_ID` + `registerLocaleData(localeFr)` | keep in bootstrap `providers` |
| `I18nPipe` (declared/exported in module) | standalone pipe, imported where used |

`provideStore`/`provideState`/`provideEffects` are NgRx ≥15, so this mapping is valid at Task 5 (NgRx 19).

## Risks / edge cases

- **TS 5→6.0** is the largest jump: removed/renamed compiler options. Let `ng update` migrate, then
  resolve residuals; `skipLibCheck` may be needed for `auth0-js`/old types.
- **Zoneless default at v21**: must keep `provideZoneChangeDetection()`; jQuery/Fancybox/Bootstrap/
  auth0 callbacks depend on Zone.js.
- **OnPush default at v22** can strand imperative UI state → use the Task 8 audit.
- **Provider relocation** (Task 5) is the most error-prone manual step; a missed provider causes a
  `NullInjectorError` at runtime. Build green is not enough — smoke every routed area.
- **`relativeLinkResolution` removal** can change relative `routerLink` resolution.
- **Global scripts** (`declare const $`) must still load under the application builder.
- Keep the bundle budgets (`initial` 2 MB warn / 3 MB error) passing.

## Validation checklist (run after every hop)

- `ng build` + `ng build --configuration=production` succeed; budgets pass.
- Public site: home (slides, videos, promo), brands, category list + details, article detail
  (currency, gallery lightbox, YouTube/Fancybox), search, homemade knives + custom-knife (lightbox),
  walking sticks, steels, services, about, error page.
- Cart wizard: add/remove, engraving modal, shipping by country, promo tiers, PayPal sandbox pay + success.
- Auth: login, `authcallback`, logout, profile view/edit, orders.
- Admin (guard): login + CRUD for products, advanced products, categories, slides, videos, brands,
  orders, users; CSV export (`file-saver`); toast notifications.
- Language switch (fr/nl/en) via `trans` pipe.
- Deployable `dist` only after the v22 smoke passes.

## Out of scope

- Removing Zone.js / full zoneless migration.
- `auth0-js` → `auth0-spa-js`.
- Removing jQuery / Fancybox / Bootstrap JS.
- Tightening TS strictness or adding ESLint.
- Adding unit/E2E test infrastructure.
- Angular Material adoption or migrating custom i18n to `@angular/localize`.

## Rollback

Each hop is one commit on `upgrade/angular-22`; the pre-upgrade `dist` is retained. Revert or
redeploy the last known-good `dist` if a hop fails smoke testing.
